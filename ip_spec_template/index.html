    HyperBus – Specification

    Version: 0.1
    Date: 2025-11-25
    Author:

    1. Overview

    Brief description of the IP: - Purpose - Usage context - Supported standards/protocols - High-level functionality

    2. Features

    • Parameterizable (WIDTH, DEPTH)
    • Throughput: 1 item/cycle
    • Status flags: empty, full, almost-full
    • Synchronous/asynchronous reset
    • Backpressure support

    5. Interfaces

    5.1 Port List (SystemVerilog)

    module <ip_name> (
    input  logic        clk,
    input  logic        rst_n,
    input  logic        push,
    input  logic        pop,
    input  logic [7:0]  data_in,
    output logic [7:0]  data_out,
    output logic        full,
    output logic        empty
);

    5.2 Signal Description

    Signal Dir Width Description
    clk In 1 Clock input
    rst_n In 1 Active-low reset
    push In 1 Write request
    pop In 1 Read request
    data_in In 8 Data to be written
    data_out Out 8 Data output
    full Out 1 FIFO full indicator
    empty Out 1 FIFO empty indicator

    7. Parameters & Configuration

    Parameter Default Description
    WIDTH 8 Data bus width
    DEPTH 16 FIFO depth

    8. Reset Behavior

    • Active-low asynchronous reset.
    • On reset:
    • Internal pointers cleared
    • Status flags cleared
    • Memory content unspecified

    9. Clocking & Power

    9.1 Clock Domain

    • Single clock domain
    • No internal CDC logic

    9.2 Power Considerations

    • Optional clock gating support

    10. Register Map (if applicable)

    10.1 Register Summary

    Address Name R/W Description
    0x00 CTRL R/W Enable, reset
    0x04 STATUS R Full, empty

    10.2 Register Details

    10.2.1 CTRL Register (0x00)

    Bit Name R/W Description
    0 EN R/W Enable IP
    1 RESET W Software reset
